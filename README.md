# Smart Home mit Home Assistant

Privates Hobbyprojekt: Energie, Sicherheit und Komfort mit Home Assistant.

Die Website liegt in `index.html`, die anonymisierten Konfigurationsbeispiele im Ordner `yaml/`.

Alle Beispiele sind anonymisiert – Namen, Geräte-IDs, Adressen und Seriennummern wurden durch Platzhalter ersetzt. Vor der Verwendung die Entity-IDs an das eigene System anpassen.
